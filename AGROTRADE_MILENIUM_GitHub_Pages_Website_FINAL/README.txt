# AGROTRADE MILENIUM S.L. — GitHub Pages Website

This folder contains a ready-to-upload static website.

## Files
- `index.html` — main website
- `styles.css` — design and responsive layout
- `assets/agrotrade-logo.png` — supplied company logo

## Before publishing
Open `index.html` and replace:
- `YOUR-EMAIL-HERE`
- `YOUR PHONE / WHATSAPP HERE`

Do not publish a guessed or invented email address.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a new **public** repository, for example:
   `agrotrade-milenium-website`
3. Upload `index.html`, `styles.css`, and the `assets` folder.
4. Open the repository's **Settings → Pages**.
5. Under the publishing source, choose the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the live Pages URL under the Pages settings.

GitHub Pages looks for an `index.html` entry file and can publish static files from a repository. See the official GitHub Pages documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Important
GitHub's current documentation says GitHub Pages is not intended or allowed to be used as a free web-hosting service for an online business or a website primarily directed at facilitating commercial transactions. For a commercial company website, consider a business-friendly static host such as Cloudflare Pages or Netlify instead.
